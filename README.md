# 音声入力SOAPノート (Voice SOAP Notes)

医療、リハビリテーション、看護、介護現場向けの、Web Speech APIを活用したリアルタイム音声入力＆キーワード自動判定によるSOAPノート作成Webアプリケーションです。

---

## 🌟 主な機能

1. **リアルタイム音声入力（Web Speech API）**
   - 「録音開始」ボタンを押すだけで、ブラウザ標準の音声認識がスタートします。
   - 話した言葉がリアルタイムに画面へ入力され、暫定認識テキストと確定テキストをスムーズに表示します。
   - 録音中は経過タイマーと視覚的なパルスアニメーションが表示されます。

2. **テキスト編集・確認**
   - 「録音停止」ボタンを押すと、確定された全文が表示されます。
   - テキストエリア内で自由に修正・加筆が可能です。
   - 「例文を挿入」ボタンで、実際の臨床・リハビリを想定したサンプル文章をワンクリックで入力してテストできます。

3. **キーワードベースのSOAP自動振り分け**
   - 「SOAP変換」ボタンを押すと、テキストを文ごとに分割し、キーワード判定ルールに基づいて各セクションへ自動分類します。
   - 該当キーワードのタグ（バッジ）が表示され、なぜその分類になったかが一目で分かります。
   - いずれのキーワードにも一致しない文は「未分類」カードにまとめられます。

4. **カードごとの柔軟な編集・移動・コピー**
   - 文ごとに別のカテゴリ（S/O/A/P/未分類）への手動移動や削除が可能です。
   - 各セクション（S/O/A/P）ごとの「個別コピー」ボタンを装備。
   - 「SOAP全体をコピー」ボタンで、電子カルテや報告書にそのまま貼り付けられる整形テキストを一括コピーできます。

5. **洗練されたモダン＆クリーンデザイン**
   - 白背景を基調とした、清潔感と視認性の高い医療向けデザイン。
   - SOAP各セクションを明確に色分け（**S = 青**、**O = 緑**、**A = 黄**、**P = 赤**、**未分類 = グレー**）。
   - 日本語が美しく読みやすいゴシック体（Noto Sans JP / system-ui）。
   - スマートフォン・タブレット・PCに完全対応したレスポンシブデザイン。

## 📋 SOAP振り分けキーワードルール

| 分類 | 名称 | カラー | 判定キーワード例 |
| :---: | :--- | :---: | :--- |
| **S** | 主観的情報 (Subjective) | **青 (Blue)** | `痛い`, `つらい`, `しびれる`, `だるい`, `動かしにくい`, `不安`, `眠れない`, `訴え`, `違和感`, `重い` など患者の自覚症状に関する言葉 |
| **O** | 客観的情報 (Objective) | **緑 (Green)** | `ROM`, `MMT`, `度`, `cm`, `kg`, `mmHg`, `回`, `秒`, `歩行`, `握力`, `バイタル`, `腫脹`, `熱感`, `発赤`, `血圧`, `体温`, `脈拍` など検査値・測定値・所見 |
| **A** | 評価・分析 (Assessment) | **黄 (Yellow)** | `考えられる`, `原因`, `問題`, `改善`, `低下`, `制限`, `リスク`, `評価`, `要因`, `困難`, `良好` など分析・専門的判断 |
| **P** | 治療計画 (Plan) | **赤 (Red)** | `プログラム`, `目標`, `実施`, `継続`, `指導`, `週`, `回`, `セット`, `退院`, `自主トレ`, `ストレッチ`, `訓練`, `計画` など治療方針・指導計画 |
| **？** | 未分類 | **グレー** | 上記キーワードのいずれにも該当しなかった文 |

## 🚀 起動方法

### 方法1: `start.bat` をダブルクリック（一番簡単・推奨）
フォルダー内の `start.bat` をダブルクリックするだけで、Windows標準のPowerShellによりローカルWebサーバーが立ち上がり、ブラウザが自動的に開きます。
（PythonやNode.jsなどの追加インストールは不要です）

### 方法2: PowerShellから直接起動
```powershell
cd C:\Users\osach\.gemini\antigravity\scratch\voice-soap-notes
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

### 方法3: ブラウザで直接開く
`index.html` をダブルクリックしてブラウザで開くことも可能です。
※ Web Speech API（マイク機能）はブラウザのセキュリティ仕様上、`http://localhost` 等のWebサーバー経由でのアクセスが最も安定して動作します。
